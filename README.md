## Project Profile

SIPKESMAS adalah sistem informasi berbasis web yang dikembangkan untuk mendukung pengelolaan data layanan kesehatan masyarakat, khususnya pada lingkungan kerja Puskesmas dan Dinas Kesehatan Kabupaten Ponorogo.

## Project Status

Status terbuat saat sedang berlangsung dalam masa Praktik Kerja Lapangan di Dinas Kesehatan Ponorogo.

## Repository

Proyek ini merupakan bagian dari pengembangan sistem informasi SIPKESMAS untuk mendukung proses kerja dan layanan berbasis digital di lingkungan kesehatan masyarakat.

## Website Notes

Sistem ini digunakan sebagai platform digital untuk mengelola informasi perawatan kesehatan masyarakat, data puskesmas, keluarga, kunjungan, serta proses informasi kesehatan secara terstruktur.
